Overview

Ne yapar, ne yapmaz

What it does, and doesn't do

Servis Service

TCMB'nin günlük döviz kuru belgesi çekilir, 15 dakikalık tazelik penceresiyle önbelleğe alınır ve kendi JSON sözleşmemizle sunulur. Amaç; her istemcinin TCMB'nin XML formatını tek başına ayrıştırmak zorunda kalmadan, öngörülebilir tek bir kaynaktan okuması.

TCMB's daily exchange rate bulletin is fetched, cached within a 15-minute freshness window, and served through our own JSON contract — so no client has to parse TCMB's raw XML on its own.

Sınır Boundary

Kurlar TCMB'nin o günkü resmî yayınıdır — anlık piyasa kuru değildir. Bu servis TCMB'ye ait değildir; TCMB'nin herkese açık verisini tüketen bağımsız bir mikroservistir. Erişim için bir API anahtarı gerekir; anahtarınız yoksa servisi size sağlayan ekiple iletişime geçin.

Rates reflect TCMB's official daily publication — not a live market feed. This service is not affiliated with TCMB; it is an independent microservice consuming TCMB's public data. An API key is required; if you don't have one, contact whoever provisioned the service for you.

Any language, the same contract

Aşağıdaki her sekme aynı isteği farklı bir yazılım dilinde gösterir. Servisi kendi dilinizde tüketmek için tek ihtiyacınız olan: taban adres, X-API-Key başlığı ve JSON gövdesini okuyan bir istemci.

Each tab below shows the same request in a different language. To consume the service from your own stack, all you need is the base URL, the X-API-Key header, and a client that reads JSON.

curl "https://kur.etiyapi.com/api/v1/rates?symbols=USD,EUR" \
  -H "X-API-Key: <anahtarınız>"
// JavaScript — fetch
const res = await fetch(
  "https://kur.etiyapi.com/api/v1/rates?symbols=USD,EUR",
  { headers: { "X-API-Key": apiKey } }
);
const { rates } = await res.json();
# Python — requests
import requests

res = requests.get(
    "https://kur.etiyapi.com/api/v1/rates",
    params={"symbols": "USD,EUR"},
    headers={"X-API-Key": api_key},
)
rates = res.json()["rates"]
// PHP — cURL
$ch = curl_init("https://kur.etiyapi.com/api/v1/rates?symbols=USD,EUR");

Sözleşmeyi sabit tutun

Keep the contract fixed

Hangi dili kullanırsanız kullanın, uç nokta ve yanıt şeması aynıdır. Yeni bir dil için istemci yazarken TCMB'nin ham XML'ini değil, yalnızca bu servisin JSON'unu hedefleyin.

The endpoint and response schema stay identical regardless of language. When writing a client in a new language, target this service's JSON — never TCMB's raw XML.

Anahtarı başlıkta taşıyın

Carry the key in the header

Kimlik doğrulama tek bir başlıkla yapılır: X-API-Key. Anahtarı sorgu dizesine, log satırına ya da istemci koduna gömmeyin.

Authentication is a single header: X-API-Key. Never embed it in the query string, log lines, or client-side code.

429 ve 503'ü ayırt edin

Distinguish 429 from 503

Yeni bir dil desteği eklerken istemcinizin 429 (kota) durumunda Retry-After başlığını okumasını, 503 (kur yok) durumunda ise farklı davranmasını sağlayın.

When adding support for a new language, make sure your client reads the Retry-After header on 429 (quota) and handles 503 (no rate available) differently.

Listede olmayan bir dil mi kullanıyorsunuz?

Using a language that isn't listed?

Yukarıdaki istekleri temel alan ince bir sarmalayıcı yazmanız yeterli: taban adresi, X-API-Key başlığını ve rates dizisini okuyan birkaç satır kod, kendi dilinizde tam bir istemci için yeterlidir.

A thin wrapper around the request above is all it takes: a few lines that set the base URL, attach the X-API-Key header, and read the rates array give you a complete client in your own language.

Sınırlar açık olsun

Know the limits up front

Her anahtarın dakika başına istek sınırı vardır. Aşıldığında 429 ve ne zaman tekrar denenebileceğini söyleyen bir Retry-After döner.

Each key carries a per-minute request limit. Exceeding it returns 429 together with a Retry-After header telling you when to retry.
