Servis çalışıyor / Operational

Genel bakış / Overview

TR

TCMB'nin günlük döviz kuru belgesi çekilir, 15 dakikalık tazelik penceresiyle önbelleğe alınır ve kendi JSON sözleşmemizle sunulur. Kurlar TCMB'nin o günkü resmî yayınıdır — anlık piyasa kuru değildir.

Erişim için API anahtarı gerekir; anahtarınız yoksa servisi size verenle iletişime geçin.

EN

Fetches TCMB's daily bulletin, caches it within a 15-minute freshness window and serves it through our own JSON contract. Rates reflect TCMB's official daily publication — not a live market feed.

An API key is required. If you don't have one, contact whoever gave you this address.

İstek / Request

curl "https://kur.etiyapi.com/api/v1/rates?symbols=USD,EUR" \
  -H "X-API-Key: <anahtarınız / your key>"
symbols Opsiyonel. Verilmezse tüm kurlar döner. / Optional — omit to receive every supported currency.

Cevap / Response

{
  "base": "TRY",
  "rateDate": "2026-08-12",   // TCMB yayın günü / publication date
  "rates": [
    { "currency": "USD", "rate": 0.0209, "unitPrice": 47.73 }
  ]
}
rate 1 TRY kaç birim eder / how much 1 TRY is worth in that currency
unitPrice 1 birim kaç TRY eder / how much one unit is worth in TRY

Kota / Rate limit

TR

Her anahtarın dakika başına istek sınırı vardır. Aşıldığında 429 ve ne zaman tekrar denenebileceğini söyleyen Retry-After döner.

EN

Each key carries a per-minute request limit. Exceeding it returns 429 together with a Retry-After header telling you when to retry.

200Kur döndü / rates returned
401Anahtar yok ya da tanınmıyor / missing or unknown key
429Kota aşıldı / rate limit exceeded
503Elde hiç kur yok / no rate available at all
