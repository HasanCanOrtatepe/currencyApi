currency-api

TCMB (Türkiye Cumhuriyet Merkez Bankası) tabanlı döviz kuru servisi. TRY exchange rate API, backed by Türkiye's Central Bank (TCMB).

TR

Bu servis ne yapar?

TCMB'nin günlük döviz kuru belgesini çeker, 15 dakikalık bir tazelik penceresiyle cache'ler ve kendi JSON sözleşmesiyle sunar. Kurlar TCMB'nin o günkü resmî yayınıdır — anlık piyasa kuru değil, en fazla 15 dakika gecikmeli TCMB verisidir.

Erişim için bir API anahtarı gerekir. Anahtarınız yoksa servisi size verenle iletişime geçin.

EN

What is this?

A TRY exchange rate API backed by TCMB (Central Bank of the Republic of Türkiye)'s daily published rates. Rates are cached for up to 15 minutes — this reflects TCMB's official daily publication, not a live market feed.

An API key is required. If you don't have one, contact whoever gave you this address.

Örnek istek / Example request

curl "https://kur.etiyapi.com/api/v1/rates?symbols=USD,EUR" \
  -H "X-API-Key: <anahtarınız / your key>"

Cevap / Response

{
  "base": "TRY",
  "rateDate": "2026-08-12",
  "rates": [
    { "currency": "USD", "rate": 0.0209, "unitPrice": 47.73 }
  ]
}
rate1 TRY kaç <currency> eder / how much 1 TRY is worth in <currency>
unitPrice1 <currency> kaç TRY eder / how much 1 <currency> is worth in TRY

Kota / Rate limit

TR: Her anahtarın dakika başına bir istek sınırı vardır (aşılırsa 429 + Retry-After döner). Sınır anahtarınıza göre değişebilir.

EN: Each key has a per-minute request limit (returns 429 + Retry-After when exceeded). The limit may vary per key.
