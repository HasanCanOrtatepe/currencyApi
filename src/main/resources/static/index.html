TCMB Tabanlı Kur Servisi · TCMB-Backed FX API

currency-api

TR: TCMB'nin resmî döviz kurlarını normalize edip önbellekli, anahtarlı bir API olarak sunar.

EN: Serves TCMB's official exchange rates through a cached, key-protected API.

Etiya Telekom Lite projesi için geliştirildi · Built for the Etiya Telekom Lite project

Bu servis ne yapar? / What does it do?

TR

TCMB'nin günlük döviz kuru belgesini çeker, 15 dakikalık bir tazelik penceresiyle önbelleğe alır ve kendi JSON sözleşmesiyle sunar. Kurlar TCMB'nin o günkü resmî yayınıdır — anlık piyasa kuru değil, en fazla 15 dakika gecikmeli TCMB verisidir.

Erişim için bir API anahtarı gerekir. Anahtarınız yoksa servisi size verenle iletişime geçin.

EN

Fetches TCMB's daily exchange-rate bulletin, caches it for up to 15 minutes, and serves it through our own JSON contract. Rates reflect TCMB's official daily publication — not a live market feed.

An API key is required. If you don't have one, contact whoever gave you this address.

Örnek istek / Example request

curl "https://kur.etiyapi.com/api/v1/rates?symbols=USD,EUR" \
  -H "X-API-Key: <anahtarınız / your key>"

Cevap / Response

{
  "base": "TRY",
  "rateDate": "2026-08-12",
  "rates": [
    { "currency": "USD", "rate": 0.0209, "unitPrice": 47.73 }
  ]
}
rate1 TRY kaç <currency> eder / how much 1 TRY is worth in <currency>
unitPrice1 <currency> kaç TRY eder / how much 1 <currency> is worth in TRY

Kota / Rate limit

TR

Her anahtarın dakika başına bir istek sınırı vardır (aşılırsa 429 + Retry-After döner). Sınır anahtarınıza göre değişebilir.

EN

Each key has a per-minute request limit (returns 429 + Retry-After when exceeded). The limit may vary per key.
